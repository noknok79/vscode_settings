# Technical Documentation

Analyze the selected repository or files.

Generate professional technical documentation covering:

1. Overview
2. Purpose and scope
3. Architecture
4. Prerequisites
5. Technical components
6. Configuration
7. Deployment procedures
8. Validation
9. Troubleshooting
10. References

Requirements:

- Use GitHub Flavored Markdown.
- Reference relevant source files.
- Use Mermaid diagrams when useful.
- Follow applicable technical-writing instructions.
- Use the technical-documentation skill when available.
- Never invent configurations or execution results.
- Identify missing information.
