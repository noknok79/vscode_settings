# Global DevOps Instructions

For all DevOps engineering tasks:

- Diagnose the root cause before modifying code.
- Prefer the smallest safe change.
- Never guess technical syntax or configuration.
- Consult current official documentation when behavior is version-dependent.
- Prefer Microsoft Learn for Azure and Azure DevOps.
- Prefer HashiCorp documentation for Terraform.
- Prefer Kubernetes documentation for Kubernetes.
- Do not rewrite working code unnecessarily.
- Do not weaken security to make an error disappear.
- Apply least privilege.
- Never expose secrets.
- Do not introduce unrelated changes.
- Validate changes using the appropriate technology tooling.
- Review the Git diff before completing modifications.
